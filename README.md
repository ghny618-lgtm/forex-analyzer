# Forex Analyzer — تحليل فوركس حقيقي (Twelve Data)

مشروع واحد كامل (سيرفر واحد يشغّل كل شيء)، بدون أي بيانات وهمية، مبني على أسعار حقيقية من Twelve Data.

---

## ⚡ التشغيل في 4 خطوات فقط

**الخطوة 1 — احصل على مفتاح مجاني**
اذهب إلى https://twelvedata.com/pricing → أنشئ حسابًا مجانيًا → انسخ الـ **API Key** من لوحة التحكم.

**الخطوة 2 — ضع المفتاح في مكان واحد**
افتح ملف `.env.example` وأعد تسميته إلى `.env`، ثم استبدل السطر:
```
TWELVE_DATA_API_KEY=ضع_مفتاحك_هنا
```
بمفتاحك الحقيقي. **هذا هو المكان الوحيد في كل المشروع الذي تضع فيه المفتاح.**

**الخطوة 3 — التثبيت والتشغيل**
افتح Terminal (أو Command Prompt) داخل مجلد المشروع ثم نفّذ:
```bash
npm install
npm start
```

**الخطوة 4 — افتح الموقع**
افتح المتصفح على: **http://localhost:4000**

هذا كل شيء — لا حاجة لأي تعديل برمجي إضافي، ولا خطوات بناء (build) منفصلة للواجهة.

---

## ما الذي يعمل فعليًا خلف الكواليس

- عند كل تحديث (كل 15 ثانية تلقائيًا)، يطلب السيرفر شموع الأسعار الحقيقية من Twelve Data عبر `/time_series` لنفس الزوج والفريم المختارَين في الواجهة.
- تُحسب المؤشرات (EMA50, EMA200, RSI14, MACD, ATR14) من هذه الأسعار الحقيقية فقط عبر مكتبة `technicalindicators`.
- الإشارة تُحسب بقاعدة ثابتة لا عشوائية فيها:
  - **BUY 🟢**: EMA50 فوق EMA200 **و** RSI14 فوق 50 **و** MACD فوق خط الإشارة.
  - **SELL 🔴**: EMA50 تحت EMA200 **و** RSI14 تحت 50 **و** MACD تحت خط الإشارة.
  - **WAIT 🟡**: أي حالة أخرى (والسبب الدقيق يظهر تحت الإشارة).
- تظهر أسهم ▲/▼ على الشارت تلقائيًا في كل نقطة تغيّرت فيها الإشارة تاريخيًا إلى BUY أو SELL — محسوبة من نفس بيانات الأسعار الحقيقية، وليست موضوعة يدويًا.
- لا يوجد تنفيذ صفقات ولا اتصال بأي حساب تداول — تحليل وعرض فقط، تمامًا كما طلبت.

---

## رسائل الأخطاء الواضحة

إذا حدث أي من التالي، ستظهر رسالة حمراء واضحة في أعلى الصفحة بدل شاشة فارغة أو بيانات وهمية:
- المفتاح غير مكتوب بعد في `.env`.
- المفتاح خاطئ.
- انتهت نقاط الاستخدام (API credits) اليومية لخطتك المجانية.
- تجاوزت الحد المسموح من الطلبات في الدقيقة (Rate limit) — أعد المحاولة بعد دقيقة.
- تعذّر الوصول إلى الإنترنت من جهة السيرفر.

---

## لماذا سيرفر Backend وليس فقط صفحة HTML؟

لأن مفتاح API يجب ألا يظهر أبدًا داخل كود المتصفح (أي شخص يمكنه فتح "أدوات المطوّر" ويسرقه). لذلك:
- المفتاح موجود فقط في `.env` على جهاز السيرفر.
- المتصفح لا يتحدث إلا مع سيرفرك المحلي (`/api/analysis`)، وسيرفرك هو من يتحدث مع Twelve Data.

## هيكل الملفات

```
forex-analyzer/
├── .env.example        ← انسخه إلى .env وضع مفتاحك هنا فقط
├── package.json
├── server.js            ← نقطة التشغيل، يخدم الواجهة + الـ API معًا
├── src/
│   ├── config.js         ← يقرأ المفتاح والأزواج والفريمات (مصدر واحد)
│   ├── twelveData.js      ← الاتصال الحقيقي بـ Twelve Data + رسائل الأخطاء
│   ├── indicators.js       ← حساب EMA/RSI/MACD/ATR
│   ├── signal.js            ← قاعدة BUY/SELL/WAIT بالضبط كما طلبت
│   └── cache.js              ← تخزين مؤقت بسيط لحماية حد الطلبات المجاني
└── public/               ← الواجهة (صفحة واحدة، بدون خطوة بناء)
    ├── index.html
    ├── style.css
    └── app.js
```

## ملاحظة أمانة تقنية

لا تتوفر لدي بيئة بوصول إنترنت فعلي لأشغّل المشروع فعليًا وأتحقق منه مقابل Twelve Data قبل تسليمه. تحققت من سلامة كل ملفات الكود عبر فحص syntax كامل (Backend وFrontend)، وجميعها خالية من الأخطاء البرمجية، لكن التحقق النهائي من نجاح الاتصال الفعلي بـ API يحتاج منك تشغيل الخطوات أعلاه بمفتاحك الحقيقي.

## إخلاء مسؤولية

الإشارات أداة تحليل فني تقليدي وليست توصية استثمارية ولا ضمانًا للربح. تداول الفوركس ينطوي على مخاطر خسارة كبيرة.
